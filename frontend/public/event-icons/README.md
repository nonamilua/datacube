# Event SVG assets

Two local sets cover all 18 event labels currently mapped in `frontend/src/scrambles.ts`.

- `detailed/`: original namicubes artwork with projected puzzle shapes and piece divisions. Blindfold, hand, multiple-puzzle and pencil markers distinguish practice events. The multiple-puzzle symbol identifies `3mbld`; it does not imply support for multiple cube selections.
- `reference/`: MIT-licensed [cubing/icons](https://github.com/cubing/icons) artwork. Its original license is retained in `reference/LICENSE`; `reference/SOURCE.json` records the pinned upstream commit, original file hashes and local changes.
- `manifest.json`: maps exact app event labels to both asset URLs. The `square 1` label uses the filename `square-1.svg`.
- `preview.html`: standalone dark preview with a switch between both sets. Open it through Vite at `/event-icons/preview.html` or directly as a local file.
- `contact-sheet.svg`: overview of the detailed set.

The detailed assets are original project source, generated by `scripts/generate_event_svgs.py`. They do not contain copied upstream geometry. The generator also rebuilds the preview and manifest; it expects the existing reference files and uses Python's standard library only.

All SVGs are scalable and use `currentColor`. The detailed set shares a `0 0 128 128` viewBox; upstream reference icons retain their own viewBoxes. Inline SVG inherits CSS `color`; an external SVG loaded with `<img>` does not inherit the parent page's color. For dynamic theme colors, use inline SVG or a CSS mask. Keep color choices in the application's existing palette variables.

Use about 48–96px for the detailed set so big-cube divisions and event markers remain legible. Use the reference set for smaller controls. Keep event labels available: even detailed artwork cannot reliably distinguish 6x6 from 7x7 at very small sizes. Pair the visible icon with an event label or give its control an accessible event label and mark the decorative SVG `aria-hidden="true"`.

These are event illustrations, separate from the existing Lucide navigation icons. Assets and preview are provided for review; the current namicubes interface is unchanged.
