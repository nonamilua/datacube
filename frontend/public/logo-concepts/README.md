# Datacube logo

The selected logo is `03-nine-tiles.svg`: nine violet cube stickers with five transparent dice pip cutouts. It retains the enlarged pips (radius 6 in the 128 by 128 viewBox) and the current brand violet, `#cc8eff`. The background and pips are transparent.

Open `preview.html` to view the symbol beside datacube and dados&cubos in Roboto Mono, including 24px, 40px and 64px samples. The standalone SVG contains geometry only and does not depend on fonts. Preview wordmarks remain editable text.

The discarded concepts and their contact sheet have been removed. The site now uses this SVG as its favicon and header symbol, beside the responsive two-line wordmark.
